# Legion TD Community Enhanced 1.1.1

LTDCE is the new name for the Warcraft III map previously released as Legion TD FEmbussy. The new title appears in the custom game list, the F9 information panel and the in-game map labels. The website and multilingual player guide use the same name.

This release updates the map’s identity. The gameplay and balance are carried over from 1.1.0, and the local match record uses the same save format.
